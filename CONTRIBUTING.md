# Contributing

Shores Dashboard is open-source so residents can audit the code and the editorial process.

## Reporting an issue

If you spot something wrong on the site:

- **Factual error** → open a GitHub Issue with a link to the item and a link to the corrected source.
- **Broken scraper / missing news** → open an Issue with the source name and roughly when you noticed.
- **Editorial concern** (tone, framing) → open an Issue referencing [EDITORIAL.md](./EDITORIAL.md).

## Pull requests

PRs welcome for:

- Bug fixes in scrapers
- Layout / accessibility improvements
- New civic data sources (must meet criteria below)

PRs not accepted for:

- Editorial content changes (recaps, blurbs) — submit as Issues so they go through the review process
- New sponsor placements — handled separately, see EDITORIAL.md
- Political content of any kind

## Criteria for adding a new source

1. Public, free to access.
2. Provides RSS or a stable HTML structure.
3. Covers St. Clair Shores or directly affects it.
4. Not partisan or candidate-affiliated.

## Security

If you find a security issue (exposed token, scraper that could be weaponized, etc.), do **not** open a public Issue. Email admin@shoresdashboard.com directly.
